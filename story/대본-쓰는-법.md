# 대본 쓰는 법

대본은 `story/ch1.js`, `ch2.js` … 파일 안의 백틱(`) 사이에 한 줄에 하나씩 씁니다.
줄 맨 앞의 말머리로 종류가 정해집니다. 대사만 고칠 때는 `이름:` 뒤의 글자만 바꾸면 됩니다.

> ⚠️ 대본 안에서는 백틱(`)을 쓰지 마세요. 그 문자가 대본의 시작과 끝 표시입니다.

| 쓰는 법 | 화면에서 |
|---|---|
| `사가랴: 대사` | 이름표가 붙은 대사 |
| `(해설) 문장` | 이름 없는 해설(명조체) |
| `# 표제 1장 소망 \| 제목 \| 1일차 · 눅 1:5-7` | 검은 화면의 제목 카드 |
| `# 장면 지붕` | 배경 그림 바꾸기 (그림 이름은 js/art.js에 있음) |
| `말씀 [눅 1:13] 본문` | 말씀 카드 (개역개정은 1~2절 이내로) |
| `성경읽기: 눅 1:5-25` | "성경 펴서 읽기" 카드 |
| `메모: 문장` | "그때 그곳" 배경 설명 카드 (성경 밖 정보) |
| `질문: 묻는 말 \| 건너뛰기 버튼 글자` | 인물의 질문 → 일기장 저장 (건너뛰기 글자는 생략 가능) |
| `미션: 문장` | 오늘의 미션 카드 |
| `게임: 등불` | 미니게임 (`등불`, `짐꾸리기`, `제비`, `톡톡 양세기`, `따라쓰기 요한`, `퍼즐 눅 1:38` 등. 목록은 `js/games.js`) |
| `게임: 퍼즐 눅 1:38` | 말씀 퍼즐: 그 구절을 조각내서 순서대로 맞추기 |
| `# 모드 채팅 방 이름 \| 오른쪽 인물` | 여기부터 대사가 메신저 말풍선으로 나옴. `\|` 뒤 인물은 오른쪽(노란 말풍선). `○○의 서판:`은 서판 말풍선 |
| `# 모드 영화` | 여기부터 '보는 날': 저절로 넘어가고 위아래 검은 띠 |
| `# 모드 보통` | 원래대로 |
| `효과: 별깜빡` | 장면 효과 |
| `음성: v-1-3` | audio/v-1-3.mp3 재생 (말씀 카드 바로 앞에 두면 카드와 함께 들림. 성우·대사 목록: `docs/03-음성-성우.md`) |
| `사가랴(놀람): 대사` | 대사창 옆 초상에 표정 (기본·웃음·놀람·슬픔·걱정·결심·감동·두려움·기쁨) |
| `묵상:` | 말씀 묵상 화면 (안 쓰면 편 맨 끝에 자동으로 들어감) |

## 말씀 묵상과 카드

- 편 끝 '말씀 묵상'에 나오는 본문은 `story/episodes.js`의 `read`(예: `'눅 1:5-7; 시 85:10'`)로 정합니다.
- 본문 글자는 `story/bible.js`에서 가져옵니다. `read`나 카드 구절(`card.key`)을 바꿨다면 `python3 .dev/make-bible.py`를 다시 돌려야 합니다.
- 대본의 `말씀 [...]` 인용이 원문과 같은지는 `python3 .dev/check-quotes.py`로 확인합니다.
- 카드 모양: `card.emoji`(상징), `card.key`(학생이 구절을 안 고르면 넣을 구절), `card.scene`(카드 그림으로 쓸 장면), `card.focus`(그림을 위아래 어디에 맞출지 0~1, 기본 0.8)

## 고르기와 살펴보기

```
선택: 걸으면서 무엇을 물어볼까?
- 첫째 선택지 -> 사가랴: 반응 대사 | 사가랴: 이어지는 대사
- 둘째 선택지 -> (해설) 반응
```

```
살펴보기: 둘러보자. 빛나는 곳을 눌러 봐.
* 엘리사벳 | 엘리사벳: 첫 대사 | 엘리사벳: 둘째 대사
* 대문 | (해설) 문설주가 반질반질하다.
```
- `*` 뒤의 이름은 그림 속 누를 수 있는 대상 이름과 같아야 합니다(js/art.js의 `data-hot`).
- 기본은 전부 봐야 넘어갑니다. `살펴보기(2):`라고 쓰면 두 곳만 봐도 넘어갑니다.

## 이름과 일기 불러오기

| 쓰는 법 | 바뀌는 것 |
|---|---|
| `{이름}` | 학생 닉네임 |
| `{일기}` | 이 편에서 쓴 답 |
| `{일기:1-0}` | 1장 프롤로그에서 쓴 답 |
| `{일기:1-0?어제 네가 '$'라고 했지.\|답이 없을 때 할 말}` | 답이 있으면 앞 문장($ 자리에 답), 없으면 뒤 문장 |

편 번호: 인트로 `0`, 1장 프롤로그 `1-0`, 1장 1일차 `1-1` … 성탄 `end`. 날짜와 제목은 `story/episodes.js`에 있습니다.

## "어제 미션 했어?"

따로 쓰지 않아도 됩니다. 앞 편에 미션이 있으면 다음 편 첫 장면에서 그 편 진행 인물(episodes.js의 `host`)이 자동으로 묻습니다.

## 고친 뒤 폰에 바로 반영하려면

`index.html` 아래쪽 `?v=1` 숫자를 하나 올리고(예: `?v=2`) 다시 올리면, 카톡 인앱 브라우저도 새 파일을 받습니다.
